## 背景与动机

> 卫星 3D 重建受限于高分辨率影像采集成本与大气/轨道约束，多视角数据在单时相上本质稀缺；EOGS 把 3DGS 的 tile 处理与地理配准移植到了卫星领域，但在稀疏视角下仍有四类痛点。

文章明确列出了 EOGS 在实际部署中的 **四个根本性局限**：

1. **数据稀缺（Data Scarcity）**：标准 3DGS 与 EOGS 假设有充足的多视角观测。当仅有 3~7 张稀疏视角时，优化过程会严重过拟合并产生 floater 伪影。
2. **辐射不一致（Radiometric Inconsistency）**：如 DFC2019 这类真实卫星数据，因采集时间与大气散射不同，DN 值波动很大，破坏了光度一致性假设，进而引入几何重建误差。
3. **光照与阴影变化（Illumination and Shadow Variations）**：卫星影像在不同太阳高度角下产生动态投射阴影与局部辐射差异，若不显式建模阴影，时变光照会在重建几何与渲染质量上造成严重伪影。
4. **依赖辅助数据（Dependency on Auxiliary Data）**：许多方法依赖外部 DSM 作为辅助输入或需要精确的初始点云；在数据稀缺场景下，初始化阶段极易丢失关键几何信息。

> **本文动机**：在继承 EOGS 高效框架的前提下，不依赖外部 DSM，仅用 3~7 张影像即可稳定重建。核心思想是用**基础模型单目深度先验**当作几何锚点，用**物理引导的阴影感知外观模型**解耦静态地形与动态光照，并用**自适应课程学习**动态平衡先验约束与光度保真。

## 方法

### 整体流程

GeoGS 建立在 EOGS 的 tile 处理与地理配准基础设施之上，使用为卫星影像优化的**仿射相机模型**。针对稀疏视角下 3DGS 的几何塌陷与辐射退化，GeoGS 通过三个耦合模块解决（见论文 Fig.2）：

1. **Prior Extraction Module（先验提取）**：离线一次性预处理，用基础模型与元数据生成深度图、阴影掩码与表面掩码；
2. **3DGS Optimization**：在光度+几何联合监督下渲染高斯；
3. **Adaptive Curriculum（自适应课程）**：用 Fisher 信息导出的覆盖度分数动态调整先验损失权重。

三个模块分别为：

- **(1) geometry-aware optimization**（几何感知优化，Sec.3.1）
- **(2) shadow-aware appearance modeling**（阴影感知外观建模，Sec.3.2）
- **(3) adaptive curriculum strategy**（自适应课程策略，Sec.3.3）

> 论文强调这不是对现有模型的简单组合，而是通过"物理耦合 + 自适应优化"联合解决单目深度模糊与领域辐射不一致的精心编排框架。先验用于正则化以避免退化解，而自适应课程会**逐步放松**先验影响，保证最终重建由光度一致性驱动。

### 3.1 Geometry-Aware Optimization（几何感知优化）

本模块用单目深度先验锚定重建，由此导出高度约束与表面正则化损失，防止稀疏视角下的几何塌陷。

#### 3.1.1 单目深度先验（Monocular Depth Prior）

- 用 **Depth Anything V2** 提取相对深度 `D_prior`。
- 为避免不完美先验带来的偏差，高斯中心 **μ** 在场景包围盒内**均匀随机初始化**。
- 优化过程中，渲染高度图 `A` 由 `D_prior` 通过**多尺度 Pearson loss** `L_d` 监督（公式1）。
- 这种 scale-and-shift 不变的监督能有效引导高斯走向与单目先验结构一致的高度配置。

#### 3.1.2 多尺度 Patch-wise Pearson Loss（公式1）

单目深度估计常带有空间变化的畸变（如全局倾斜、非均匀尺度），使全局相关性度量不可靠；但在小空间邻域内，局部高度关系高度一致。据此定义基于 patch 内 Pearson 相关系数的深度一致性损失：

$$
\mathcal{L}_{depth} = \frac{1}{N_p}\sum_{p\in patches}\frac{Cov(\hat{D}_p, D_{prior,p})}{\sigma_{\hat{D}_p}\,\sigma_{D_{prior,p}}}
$$

- `Cov(·)` 与 `σ` 为 patch 内协方差与标准差，`N_p` 为有效 patch 总数。
- 多个 patch 尺度 `s ∈ {32, 64}`，步长比 50%，兼顾精细与粗略结构一致性。
- 深度方差低于阈值 `τ_var` 的 patch 被排除，避免在平坦区域被噪声驱动梯度。

#### 3.1.3 基于掩码的表面正则化（Surface Regularization via Masking）

对多视角匹配病态的区域施加类别化表面正则：

- **地面平坦区 M_flat**：多阶段提取——
  1. 在 7 维特征空间（Lab 颜色、深度、法向 z、局部深度 std、梯度）上用 K-Means 聚成 **K=25** 簇；
  2. 簇级阈值剔除：mean normal z ≤ 0.92、depth std ≥ 0.03 或 gradient ≥ 0.04 的簇；
  3. 像素级硬门控滤除离群点（normal z < 0.88、gradient > 0.06、std > 0.04）；
  4. 5×5 腐蚀 + 小连通域去除（< 50 px）消除伪影。
  - 在 M_flat 内用 Laplacian 正则 `L_smooth` 惩罚高度曲率以抑制噪声。
- **水体 M_water**：水体呈镜面反射且零纹理，会导致几何塌陷。用 **SAM 3** 以文本提示 "water" 提取 M_water，并用水体平坦损失 `L_water`（公式2）惩罚其内高度梯度：

$$
\mathcal{L}_{water} = \frac{1}{|M_{water}|}\sum_{(x,y)\in M_{water}} \nabla_x A^2 + \nabla_y A^2
$$

  - 这强制水面为平面，即便残留阴影误判也不会污染高度重建。

### 3.2 Shadow-aware Appearance Modeling（阴影感知外观建模）

多日期卫星影像因太阳角与大气条件变化产生动态阴影与辐射差异。若不显式建模，优化会用几何形变来解释阴影导致的强度下降，从而破坏高度面。GeoGS 通过离线提取高保真阴影掩码并以此条件化渲染管线，解耦静态几何与瞬态光照。

#### 3.2.1 多线索阴影提取（Multi-cue Shadow Extraction）

融合几何、光谱、语义三类线索（见 Fig.4）：

- **几何与光谱锚点**：基于球面三角展开计算物理 hillshade `I`（公式3）：

$$
I = \cos(z)\cos(S) + \sin(z)\sin(S)\cos(\phi_{sun} - aspect)
$$

  - `z, S, φ_sun, aspect` 分别为太阳天顶角、地表坡度、太阳方位角、地表坡向。
  - `I ≈ 0` 指示自阴影（含掠射），并通过图像空间迭代深度偏移增强投射阴影候选。
  - 用 **Normalized Blue-Shift (NBS)** 精化：`(B − R)/(B + R + ε)`，捕捉卫星阴影特有的瑞利散射天光（B、R 为蓝/红波段，`ε = 1e-6`）。

- **基于 DINOv3 的语义传播**：使用 **DINOv3 (ViT-L/16)** 特征，以上述几何/光谱锚点作伪标签**逐场景在线训练一个线性 SVM**。这种轻量方式无需预训练即可实现场景自适应，产生密集阴影概率，并用 Guided Filter 精化以对齐 RGB 边缘。

- 水体上的假阳性由水体平坦损失 `L_water` 几何地解决（即便残留于 M_shadow 也被平面约束压制）。

#### 3.2.2 阴影条件化渲染（Shadow-conditioned Rendering）

- 基础渲染管线（继承自 EOGS）已通过仿射颜色校正建模逐相机辐射变化，并通过从太阳视点渲染计算物理阴影。
- 但物理阴影计算依赖准确场景几何，而训练早期几何尚未建立。
- **GeoGS 的做法**：在初始阶段用提取的阴影掩码作为**伪阴影**，让阴影颜色校正先学习衰减模式，再随几何稳定**线性过渡**从伪阴影到物理阴影。
- 这种 warm-start 防止光度损失在早期通过阴影诱导梯度破坏几何。

### 3.3 Adaptive Curriculum Learning（自适应课程学习）

训练在 5000 次迭代内分三阶段进行，先验强度调度 `σ(t)` 从完整结构监督过渡到场景自适应的光度精修。

**Phase 1：先验热身（0 ≤ t ≤ 1500）**
- 以光度损失 `L_photo` 开始建立初始辐射。
- 在 t=500 渐进启用 `{L_depth, L_smooth}`，在 t=1000 启用 `{L_shadow, L_resample}`。
- 总损失（公式4）：

$$
\mathcal{L} = \mathcal{L}_{photo} + \sigma(t)\,\big(\lambda_d\mathcal{L}_{depth} + \lambda_s\mathcal{L}_{smooth}\big) + \mathcal{L}_{aux}
$$

- Phase 1 中 `σ(t)=1.0`，其中（公式5）：

$$
\mathcal{L}_{aux} = w_{op}\mathcal{L}_{opacity} + w_w\mathcal{L}_{water\text{-}flat} + w_{sh}\mathcal{L}_{shadow\text{-}blend}
$$

  - `w_op=0.10, w_w=0.30, w_sh=0.01`，是与课程调度无关的常数权重约束。

**Phase 2：场景自适应衰减（T1 < t ≤ T2）**
- 用 **D-最优性导出的覆盖度分数 `C ∈ [0,1]`** 调制先验衰减。
- 由归一化观测方向 `{d_i}` 构造 Fisher 信息矩阵：`F = HᵀH`，`H = [d_1,…,d_N] ∈ ℝ^{N×3}`。
- 覆盖度分数（公式6）：

$$
C = 1 - \exp\!\Big(-\frac{\det(F)^{1/3}}{\lambda_{ref}}\Big)
$$

  - `λ_ref=1.0`。
- 衰减时长 `T2 − T1 = (T − T1)(1 − 0.4·C)`，期间 `σ(t)` 从 1.0 余弦退火到 floor 值 `φ_f`。

**Phase 3：先验地板（t > T2）**
- `σ(t)` 固定为 `φ_f = (1 − C)²`。
- 密集且各向同性覆盖的场景（`C→1`）使 `φ_f→0`，模型完全依赖光度一致性。
- 稀疏视角场景（`C→0`）保留 `φ_f→1`，全程维持几何监督。
- 这种自适应 floor 避免对良好采样区域过度正则，同时为稀疏视角提供持续结构保护。

## 损失函数

汇总各损失项及其在课程中的角色：

| 损失项 | 作用 | 权重 / 调度 |
|--------|------|-------------|
| `L_photo` | 光度一致性（基础渲染损失） | 全程，Phase 1 起建立辐射 |
| `L_depth` | 多尺度 patch-wise Pearson 深度一致性（公式1） | `σ(t)·λ_d`，课程调制 |
| `L_smooth` | M_flat 内 Laplacian 高度曲率正则 | `σ(t)·λ_s`，课程调制 |
| `L_water` | 水体平坦损失（公式2） | 常数 `w_w=0.30` |
| `L_opacity` | 不透明度正则 | 常数 `w_op=0.10` |
| `L_shadow_blend` | 伪→物理阴影过渡的阴影颜色校正 | 常数 `w_sh=0.01` |
| `L_resample` | 高斯重采样/密度控制 | t≥1000 启用 |

> 课程相关超参（全文固定，无数据集特定调参）：`λ_ssim=0.2`、`τ_var=50.0`（[0,255] 尺度）、`K=25` 簇（mean normal z > 0.92、depth std < 0.03）、`λ_ref=1.0`、`λ_min=0.4`、Phase 1 占比 0.3。

## 实验

### 数据集与设置

- **数据集**：共 7 个 AOI —— 4 个来自 **DFC2019**，3 个来自 **IARPA2016**，使用 WorldView-3 影像（含 RPC/太阳元数据）与 LiDAR DSM 真值；预处理遵循 EOGS 与 EO-NeRF。
- **跨传感器泛化**：额外使用 **SkySat** 影像，覆盖 Seville（西班牙，9 张）与 Jamsil（韩国，8 张）。
- **稀疏视角协议**：按采集日期排序，用**时间分层采样**选 N 张——将时间线均分为 N 个 bin，选每个 bin 中心最近的影像，保证确定、可复现且具自然太阳角多样性（`N ∈ {3, 5, 7}`）。
- **评估协议**：报告**几何精度 MAE（米）**而非 PSNR，因为光度指标会忽视阴影诱导的结构伪影。LiDAR 评估含 NCC 水平对齐、垂直平移校正、±10 m 离群裁剪、水/植被掩码，对所有 baseline 一致应用。
- **Baselines**：EO-NeRF、Sat-DN、Skyfall-GS、EOGS（5K 与 40K 迭代）、EOGS++（取自原文指标）。
- **实现**：基于 EOGS 代码库，5000 次 Adam 迭代，NVIDIA A100 GPU；先验提取（Depth Anything V2、DINOv3、掩码）每图 30s，跨运行摊销。

### 定性结果

- **极端稀疏鲁棒性（Fig.1, Fig.6）**：N=3 时 EOGS 出现严重 floater 与建筑立面塌陷，GeoGS 仍输出干净、结构一致的 DSM。
- **跨传感器泛化（Fig.7）**：在 SkySat（Seville、Jamsil）上，因无公开 LiDAR 真值仅做定性评估；GeoGS 在 baseline 完全几何塌陷的区域仍能恢复一致 3D 结构，保留建筑足迹与水体边界。

## 总结

- **贡献1（深度先验集成）**：用 Depth Anything V2 从单目影像估计相对深度，集成进高斯密度控制与位置优化，缓解数据稀缺。
- **贡献2（卫星专用优化）**：用物理引导的阴影感知外观模型（太阳高度元数据 + 瑞利散射 + DINOv3 语义）显式解耦静态几何与动态光照，解决辐射不一致。
- **贡献3（自适应课程学习）**：基于 Fisher 信息覆盖度分数的优化调度，按输入视角几何条件动态平衡先验约束与光度保真。
- **贡献4（无外部地理先验的稳定性）**：结合卫星元数据（RPC 模型）与估计深度先验，无需外部 DSM 或稠密点云即达高几何精度。
- **局限**：当前管线针对人工裁剪的 AOI 优化，对大规模全幅带卫星影像的可扩展性有待探索；复杂密集城市布局的重建仍是挑战。未来工作将聚焦分块优化与自监督精修以扩展到大尺度行星重建，并探索加入时间一致性的 4D 变化检测。

## 思考与启发

> 与自己研究方向（稀疏视角 3D 重建）的关联与可借鉴之处：

1. **基础模型深度先验作为几何锚点**：与卫星领域思路一致——稀疏视角下用单目深度先验（Depth Anything V2）补足多视角约束缺失。这种"以 2D 基础模型先验正则化 3DGS"的范式可直接迁移到通用稀疏视角重建，关键是设计了 **scale-shift 不变的 patch-wise Pearson loss**（而非直接回归深度）， robust 于单目深度的尺度/偏移误差，值得借鉴。
2. **先验的"渐进放松"调度**：先验是早期锚点，但最终应由光度一致性主导——用课程学习把先验权重从 1.0 余弦退火到与覆盖度相关的 floor。这避免了先验过度约束导致的细节丢失，是处理"先验有用但不可全信"的通用范式。
3. **Fisher 信息覆盖度分数**：用观测方向的 Fisher 信息矩阵 `F=HᵀH` 的 `det(F)^{1/3}` 衡量视角覆盖质量，进而自适应决定先验 floor `φ_f=(1−C)²`。这是一个**无需训练、可解析计算**的视角质量指标，对任何依赖视角覆盖的 3DGS 任务都有参考价值。
4. **阴影/瞬态的显式解耦**：卫星多日期影像的阴影类比通用场景中的瞬态物体——用 hillshade 物理模型 + DINOv3 语义在线 SVM 提取阴影掩码，并用"伪阴影 warm-start → 物理阴影过渡"避免早期几何被阴影梯度破坏。对处理光照变化的稀疏重建有启发。
5. **评估用 MAE 而非 PSNR**：在几何重建任务中，光度指标会掩盖阴影诱导的结构伪影，应直接用几何精度（MAE/米）评估。这对自己的实验设计是提醒。

> 一个可延伸的问题：GeoGS 的自适应课程依赖固定 5000 迭代与手工 phase 边界，是否可用覆盖度分数 `C` 同样自适应地决定 phase 切分点，进一步减少人工调度？
