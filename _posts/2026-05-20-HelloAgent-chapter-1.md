## 核心概念

### 什么是智能体

在人工智能领域，<span style="color: #d2603a; font-weight: bold;">智能体（Agent）</span>被定义为任何能够通过**传感器（Sensors）**感知其所处**环境（Environment）**，并自主地通过**执行器（Actuators）**采取**行动（Action）**以达成特定目标的实体。

真正能够达到"智能"的关键是**自主性**——并非被外界刺激或严格的指令（如 if-else）驱动，而是根据目标，自动选取"工具"，感知"环境"，完成目标的闭环。

![智能体与环境的交互循环](/assets/img/1.1.png)

### 智能体运行机制

Agent 的运行机制可以用一个循环来概括：<span style="color: #d2603a;">**思考 → 行动 → 观察**</span>，三个步骤周而复始，直到达成目标。

## 知识要点

### 1. 智能体分类

智能体的种类有很多，从最简单的温度感知器到复杂的自主决策系统。我们日常使用的烧水壶——水烧开了，温度达到阈值就自动停止——就可以称为一个简单的智能体。以下是几种主要的分类：

#### 反应式智能体 (Reactive Agents)

这类智能体对环境刺激做出近乎即时的响应，决策延迟极低。它们通常遵循从感知到行动的直接映射，不进行或只进行极少的未来规划。

- **优势**：速度快、计算开销低，适合需要快速决策的动态环境（如车辆安全气囊、高频交易机器人）
- **劣势**：短视，容易陷入局部最优，难以完成多步骤协调的复杂任务

#### 规划式智能体 (Deliberative Agents)

规划式智能体在行动前会进行复杂的思考和规划。它们不会立即对感知做出反应，而是先利用内部的世界模型，系统地探索各种可能性，评估不同行动序列的后果，找到最佳路径。

可以将其类比为一位棋手——不会只看眼前一步，而是预想对手的应对，规划后续几步甚至十几步的棋路。

- **优势**：战略性、有远见，能处理需要长远眼光的复杂任务
- **劣势**：时间和计算成本高，在瞬息万变的环境中可能错失时机

#### 混合式智能体 (Hybrid Agents)

现实世界的复杂任务往往既需要即时反应，也需要长远规划。因此，**混合式智能体**结合了两者的优点。

一种经典的混合架构是**分层设计**：
- **底层**：快速的反应模块，处理紧急情况和基本动作
- **高层**：审慎的规划模块，负责制定长远目标

现代 LLM 智能体展现了一种更灵活的混合模式，在"**思考-行动-观察**"循环中运作：

- **规划（Reasoning）**：LLM 分析当前状况，规划下一步行动（审议过程）
- **反应（Acting & Observing）**：与外部工具或环境交互，立即获得反馈（反应过程）

通过这种方式，智能体将一个需要长远规划的宏大任务，分解为一系列"规划-反应"的微循环，既能灵活应对环境变化，又能完成复杂的长期目标。

### 2. Agent 的核心组件

| 组件 | 作用 |
|------|------|
| LLM（大脑） | 负责推理和决策 |
| 工具 (Tools) | 执行具体操作，如搜索、计算、调用 API |
| 记忆 (Memory) | 存储上下文和多轮对话历史 |
| 规划 (Planning) | 分解任务、制定执行步骤 |

### 3. 智能体的运行机制

![Agent 运行循环](/assets/img/agent%20loop.png)

LLM Agent 通过 **思考 → 行动 → 观察** 的循环不断迭代，每一步根据之前的观察调整策略，直到达成目标。

## 收获与思考

- **收获 1**：理解了 Workflow（固定流程）和 Agent（自主决策）的本质区别——Agent 的核心在于"自主"，而非按预设脚本执行
- **收获 2**：掌握了 Agent 的四大核心组件及其相互关系
- **收获 3**：理解了三种智能体分类（反应式、规划式、混合式）各自的使用场景
- **收获 4**：学会了如何从零搭建一个简单的 Agent，有了动手实践的基础
